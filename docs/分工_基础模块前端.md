前端不建议完全交给一个人，否则该成员会成为联调瓶颈。更合理的方式是：

**成员一担任前端负责人，负责整体框架和页面集成；三个人分别完成自己业务模块对应的前端组件。**

| 成员            | 前端职责                                                    |
| ------------- | ------------------------------------------------------- |
| **成员一：前端负责人** | Vue 项目框架、整体布局、路由、状态管理、接口封装、对话区、需求展示、Agent 执行轨迹，以及最终页面整合 |
| **成员二**       | 地图、地点标记、路线折线、景点/酒店/餐厅卡片、高德地图交互                          |
| **成员三**       | 行程时间轴、预算统计、校验结果、自动调整提示、修改前后对比                           |

最终关系是：

```text
成员一
├─ 建立 Vue 前端项目
├─ 统一页面风格和数据状态
├─ 对接后端总接口
└─ 合并成员二、成员三的组件

成员二
└─ 独立完成地图相关组件

成员三
└─ 独立完成行程与预算可视化组件
```

因此，分工表中可以正式写成：

> **成员一负责前端总体设计与集成，成员二负责地图可视化模块，成员三负责行程、预算及调整结果可视化模块。**

不建议写成“成员一独立完成全部前端”，因为成员一同时还承担意图识别、需求分析和工作流编排，工作量会明显失衡。前端允许使用 AI 辅助开发，而后端和模型端要求手工编码，因此三个人共同完成各自对应的前端组件，更符合项目考核要求。
